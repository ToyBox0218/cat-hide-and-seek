# 貓咪捉迷藏 · 貓咪大對決

> 本版已獲發布核准：將操作提示移至兩個棋盤之間，雙方共用版面列以保持狀態、盤面標題與格子頂緣對齊。保留 67f7f82 為可回復的父版本。實際瀏覽器、手機操作與 P2P 驗收仍待完成。

## 操作

**單點 × 標記 ｜ 雙點肉球圖示翻格。** PC 與手機使用相同操作。大對決只有一組提示：PC 放在左右棋盤之間，分成兩行；手機放在上下兩個玩家盤面之間。提示在米色盤面容器外，不占用任何一方的格子區域。原四種玩法保留棋盤上方的一行提示。詳細規則與右鍵捷徑放在「玩法／音效」。

- 單點會稍等約 300 ms，確認不是雙點後，才加上或移除私人紫色 X。
- 300 ms 內快速點兩下同一格，才會正式翻格。雙點不會留下第一下的額外記號；已標記的格子也可雙點翻開。
- 不同格的點擊不會被合併成雙點。慢速點兩下是兩次標記操作。
- 深灰 X 是實際翻開並確認沒有貓的格子；紫色 X 是自己的私人筆記，對手看不到。
- PC 右鍵仍可作為私人標記捷徑，不必使用。它不會送出猜測或觸發傷害。
- 方向鍵移動；Enter／Space 按一次標記，快速按兩次翻格。長按不會自動連續翻格。
- 已移除記號模式開關。分區靠每區不同的顏色辨識，沒有粗黑分區線；只保留淡的普通格線。
- 棋盤採局部 touch-action: manipulation，避免雙點被當成放大，不停用整個頁面的縮放／雙指縮放。
- 放大鏡／毛線被明確選取時，依道具提示單點選目標，不會同時做一般標記或翻格。

## 試玩與連線

- 單檔 HTML 預覽會進入清楚標示的本機練習；對手不會行動，沒有模擬真人配對。
- 原始碼可執行 `node scripts/serve.js`，在同一台電腦開啟 `http://127.0.0.1:3010/`。
- 入口仍分建立房間／加入房間。房主預設大對決，也可選另外四種模式。
- 使用 `CAT-1234` 短房號或邀請連結。原有手動邀請／回覆碼備援仍保留。
- 使用附帶的 PeerJS 1.5.5 與免費 PeerJS Cloud 握手，沒有新帳號、付費服務或 TURN。嚴格 NAT／企業／校園網路可能無法直接連線。
- 更新後兩邊應重新整理頁面，使用相同版本。

## 貓咪大對決

- 固定 6×6，雙方同時各找自己的貓，可以看對手唯讀盤面；沒有輪流回合計時或道具。
- 雙方完成時鐘同步與就緒握手後，共用 3、2、1 開賽倒數；房主確認開賽前不能操作。
- 每人預設 150 HP，房主可設 50–500 HP。
- 連續命中傷害依序 5、10、15、20、25、30、35、40…；前兩次共 15。
- 找齊六隻立即獨立換盤，**HP 與傷害連鎖都延續**。不必翻完空格。
- 猜錯重設自己的傷害連鎖，不扣自己 HP。連續猜錯鎖定 2、4、6、8 秒，上限 8 秒；找到貓後下一次猜錯恢復 2 秒。
- 猜錯時盤面中央顯示倒數視窗，所有翻格與私人標記都暫停。命中冷卻仍為 0.3 秒。
- 按住、取消、失焦或過期的輸入不會在解鎖時自動觸發。斷線、重連、換盤、結束與背景切換會取消不再適用的手勢計時。
- 傷害由房主立即裁定，不等動畫結束。依房主收到動作的順序，第一個讓對方 HP 歸零的動作獲勝。
- 斷線暫停雙方；重連用房主快照恢復，60 秒無法恢復則結束、不判勝負。沒有房主遷移。

## 原有四種玩法

1. 基本對戰：共用盤面，找中續手，猜空換手，以找到數決勝。
2. 魚乾道具戰：首次正常翻空格得魚乾，最多 4；每回合最多使用一個道具。
3. 寶藏派對：鈴鐺貓值 2 分，普通貓 1 分。
4. 默契合作：共享魚乾與偵查情報，一起找完所有貓。

保留 6／12／20／24 尺寸、回合時間、共同提示、表情、再戰、暱稱／頭像與棋盤縮放；連抓上限預設關閉。非自己回合仍可單點做私人筆記，雙點不會越權猜測。

道具：放大鏡私人查看中心八鄰貓數，中心不翻；毛線選同區 2–3 個相連未解格，得知其中有沒有貓；護墊令下次正常猜空不換手且不得魚乾；沙漏增加 10 秒。合作偵查資訊原樣共享。

## 題面、公平與隱私

- 每行、每列、每個顏色區域恰一隻貓，不能八方向相鄰；區域連通且至少三格，題目有唯一解。
- 不自動畫規則推導的 X，也不阻止玩家猜邏輯上已不可能的未翻格。普通空格不顯示周圍數字。
- 大對決題庫含 73 個唯一解基底，配合對稱與驗證過的區域調整，涵蓋全部 90 種合法答案排列。雙方各抽自己的盤面，避免當前答案相同與近期直接重複；不宣稱題目實際難度完全一致。
- 對手只收到白名單公開資料，沒有隱藏答案、私人筆記或答案歷史。
- 房主檢查玩家／動作／盤面識別、重複、過期、冷卻、已翻格與連線狀態。房主瀏覽器仍可被改碼或檢查答案，不是安全伺服器；4 位房號也不是密碼。

## 美術、音效與版面

- 使用本專案生成的貓屋背景與一致的六種玩家頭像；抓貓、連鎖、肉球飛行與 HP 回饋遵守減少動態設定。
- 三組不同真實貓叫來自 Kerzoven 的 [Cat Purr & Meow](https://opengameart.org/content/cat-purr-meow)，授權 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。詳見 `assets/audio/ATTRIBUTION.md` 與 `provenance.json`。
- 錄音採隨機袋、不立即重複，最多兩聲，替換淡出並壓低音樂提示；首次操作後才載入／啟用。靜音、音量會保存。失敗時明確顯示合成備用狀態，載入完成不補播舊事件。
- 6／12／20／24 每區都有不同色碼，根據公開題面穩定排列。24 色最小 OKLab 距離 0.07628；私人紫色與確認空格深灰對所有底色的最低計算對比分別 4.8100:1、4.9663:1。不是色覺無障礙的完整認證。
- 棋盤提示使用暖色文字、紫色 X 與原創肉球 SVG，沒有底色、邊框或按鈕陰影。PC 兩側棋盤使用等寬欄位與共同列高，中央提示有獨立的 96px 空間。雙方狀態、標題、格子與收集籃子共用對齊基準，暱稱或標題換行不會單獨推低一方；米色容器貼合棋盤，不保留原有 160px 提示側欄。
- PC 依視窗寬高調整棋盤，目標包括 1280×720、1366×768、1920×1080；核心字級與標題層次保留。密集 24×24 的格子較小，手動放大可在棋盤容器內捲動。
- 原四模式玩家卡片與收集盤依內容排列。手機優先自己的棋盤，同時保留對手小盤。
